# Haunted Pyramid (Not official name yet)

A Psychological horror game where an archeologist explores through the great pyramids of Egypt uncovering artifacts within the deepest depths of the tombs. But something there does not want you to uncover these ancient items-and you can't even trust your mind to differentiate what is real or an illusion.

## Getting Started

### Required Software & Tools

* **Unreal Engine Version 5.6**: Install it via the Unreal Engine Launcher [Here](https://unrealengine.com)
* **Depending on your IDE, you'll need to install the appropriate C++ workloads for that IDE. E.g, for visual studio you need, game development with C++ and desktop development with C++.**

### Hardware Specificiations

These do not represent the requirements to actually run Unreal Engine, but the recommended system requirements for development using the engine. I am basing this information off of [Code it bros](https://www.codeitbro.com/blog/unreal-engine-5-system-requirements).

* **CPU**: Ryzen 7 7800X3D or Intel I7-14700K
* **GPU**: RTX 4070 Ti or RTX 4080 with at least 12-16GB of VRAM
* **Memory**: 64 GB RAM
* **Storage**: 1-2TB NVMe SSD


### Installation

**WARNING PAID ASSETS WILL NOT BE INCLUDED IN THE REPOSITORY DUE TO LICENSING IF I CAN ILL REPLACE THEM.**

If you want to use my project for learning, clone it, or tweak the source code, then follow these steps:

1. Clone the repository:
```bash git clone https://github.com/Warge09/Haunted-Pyramid```

2. Locate the HauntedPyramid.uproject file and open it.

3. Make sure you build C++ Code either through the editor or in your IDE as the project includes C++ Source code. 


## Game Controls

* **Move**: W A S D
* **Sprint**: Shift
* **Interact**: E
* **Inventory**: Tab
* **Swapping Equipment**: 1-6 numbers
* **Using Equipment**: Left click
* **Enable/Disable Flashlight**: E
